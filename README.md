## 🎬 게임 소개

비 내리는 금요일 밤 21시 30분. **하나은행 본점 지하 제1VIP 금고**의 물리적 도어락과 디지털 '하나인증서' 다중 암호 체계가 동시에 무력화되며 현금과 고가 담보 자산이 사라졌습니다. 침입 경보는 울리지 않았고, 방재실 CCTV는 21시 20분부터 20분간 **과거 정상 화면이 반복 재생되는 루프 스크립트**에 의해 조작되었습니다.

당신은 사건 발생 10분 뒤 소집된 **특별 수사관**입니다. 심문실에는 그 시간, 은행 보안 구역에 있던 세 사람이 앉아 있습니다.

| | 용의자 | 역할 | 겉보기 알리바이 |
| :---: | :--- | :--- | :--- |
| 👮‍♂️ | **김보안** (42) | 하나은행 본점 물리보안팀장 | 21시 10분부터 방재실에서 홀로 CCTV를 관제 |
| 👩‍💻 | **박개발** (29) | IT 금융보안 외주 솔루션 수석 엔지니어 | 3층 전산실에서 검침 시간 대비 로컬 패치 스크립트 작성 |
| 🧹 | **최청소** (55) | 야간 환경미화원 | 지하 1층 로비 청소 후 21시 15분 휴게실로 |

세 명 모두 거짓말을 하고 있습니다. 하지만 **금고를 실제로 연 진범은 단 한 명**입니다. 두 명의 거짓말은 미끼(False Lead)이고, 한 명의 거짓말은 범행입니다. 심문으로 그 차이를 가려내십시오.

## 🎮 직접 플레이 흐름

이 게임은 소개 화면을 읽고 끝나는 페이지가 아니라, 플레이어가 다음 장면으로 이동하며 단서를 모으는 추리 어드벤처입니다.

1. **타이틀** — `새 수사 시작`으로 사건을 시작합니다.
2. **사건 컷신** — 21:30 사건 발생, 21:20 CCTV 이상, 21:40 용의자 확보를 짧은 장면으로 확인합니다. `Enter` 또는 `→`로 진행하고 `←`로 되돌아갑니다.
3. **현장 조사** — 금고 복도 배경의 빛나는 지점을 눌러 네 증거를 각각 확인하고 수사 가방에 모읍니다. 네 개를 모두 모아야 심문실이 열립니다.
4. **자유 심문** — 용의자를 바꾸고 직접 질문을 입력합니다. 증거를 선택해 질문과 함께 제시할 수 있으며, 총 15턴 안에 모순을 찾아야 합니다.
5. **최종 기소** — 진범과 제출 증거를 고르면 수사 결과와 S/F 랭크 엔딩이 나옵니다. `다시 수사하기`로 사건을 처음부터 재도전할 수 있습니다.

## ✨ 주요 특징

- **선택지 없는 자유 질문** — 수사관이 직접 입력한 질문과 제시한 증거에 따라 용의자의 진술이 달라집니다.
- **실시간 바이오 피드백** — 모순을 찌르면 심박수가 뛰고 상태가 바뀝니다. 130 bpm 이상에서 용의자의 긴장이 드러납니다.
- **결정적 진술 모순 감지** — 알리바이와 증거가 정면으로 충돌하는 순간, 응답이 붉게 강조되며 "결정적 진술 모순 발생" 태그가 찍힙니다.
- **증거 대조 인터랙션** — 현장 증거 4종을 골라 질문과 함께 들이밀 수 있습니다. 무엇을 언제 들이미는지가 승패를 가릅니다.
- **멀티 엔딩 · 랭크 판정** — 진범 지목과 스모킹 건 제출의 조합에 따라 S랭크 / F랭크 엔딩이 갈립니다.
- **15회의 한정된 심문 기회** — 자원 관리의 긴장감. 의미 없는 질문은 턴만 소모합니다.

## 🕹 게임 규칙

### 1. 심문 턴 (15회)
플레이어에게 주어지는 총 질문 기회는 **15회**입니다. 자유 질문을 한 번 보낼 때마다 1턴이 차감됩니다. 15턴을 모두 쓰면 최종 기소 화면이 자동으로 열립니다. 언제든 상단의 **⚖️ 진범 최종 기소** 버튼으로 수사를 조기 종결할 수 있습니다.

### 2. 심박수 · 스트레스 게이지 (70 ~ 185 bpm)
용의자별 기본 심박수는 70~85 bpm이며, 약 2.4초 주기로 미세하게 요동칩니다.

| 심박수 | 상태 | 화면 표시 |
| :--- | :--- | :--- |
| ~ 104 bpm | 🟢 평온 | 녹색 심박 표시 |
| 105 ~ 129 bpm | ⚠️ 긴장 상태 | 긴장 수치 상승 |
| 130 bpm 이상 | 🔥 극심한 당황 (모순 노출) | 붉은 심박 표시 |

증거를 정확히 들이밀거나 급소 키워드를 찌르면 심박수가 크게 상승하며, **결정적 모순**을 맞은 용의자는 말실수(자백에 가까운 힌트)를 흘립니다.

### 3. 현장 증거 보관함 (4종)

| 아이콘 | 증거 | 내용 | 겨냥하는 인물 |
| :---: | :--- | :--- | :--- |
| 🧾 | 비상계단 자판기 결제내역 | 21시 23분 커피 결제 승인 | 김보안 |
| 📹 | CCTV 조작 로그 | 21시 20분부터 20분간 영상 루프 스크립트 실행 | 박개발 |
| 🧴 | 바닥 특수 세정제 자국 | 금고 출입문 앞 복도 왁스 카트 바퀴 자국 | 최청소 |
| 💻 | 서버 접속 MAC 주소 로그 | 21시 22분, 박개발의 맥북 MAC 주소로 금고 제어 서버 원격 접속 · 커밋 푸시 | 박개발 |

증거를 선택한 뒤 질문을 보내면 `[증거 제시: …]` 형태로 질문 앞에 붙어 전달됩니다.

### 4. 최종 지목과 멀티 엔딩

| 결과 | 조건 | 엔딩 |
| :--- | :--- | :--- |
| **S랭크 (완벽한 검거)** | 진범 **박개발** 지목 **+** 증거 **서버 MAC 주소 로그** 제출 | 완전 자백, 명예 수사관 표창 |
| **F랭크 (기소 실패)** | 김보안 또는 최청소 지목 | 미끼에 걸려 진범을 놓침 |
| **F랭크 (증거 불충분)** | 박개발 지목, 그러나 다른 증거 제출 | 결정적 증거 없이 혐의 벗음 |

## 🧠 무료 플레이 구조

현재 게임은 **별도 API 키, 서버, 유료 LLM 호출 없이** 작동합니다.

- 플레이어 질문과 첨부 증거의 핵심어를 브라우저 안의 로컬 추리 엔진이 판별합니다.
- 용의자 대사, 모순 표시, 심박 상승은 사건 규칙에 따라 기기 안에서 처리됩니다. 생성형 AI가 즉석에서 대사를 만드는 기능은 포함하지 않습니다.
- 금고 배경과 세 용의자 초상은 이 프로젝트를 위해 만든 AI 콘셉트 아트이며, 이미지 파일을 사이트에 포함해 외부 이미지 요청 없이 표시합니다.
- 예전 AI 서버 실험 파일(api/interrogate.ts, src/lib/llm.ts)은 저장소에 남아 있지만 현재 게임 화면에서 호출하지 않습니다.

이 방식으로 누구나 결제나 키 설정 없이 플레이할 수 있습니다. 자유 입력은 지원하지만 반응은 준비된 사건 규칙을 바탕으로 하므로, 질문 표현에 따라 답변이 완전히 새로 생성되지는 않습니다.

의존성은 `react`, `react-dom` 단 2개입니다. 3D 엔진 · 물리 엔진 없이 **2주 안에 버그 없이 완주**하는 것을 최우선으로 설계했습니다.

## 📂 프로젝트 구조

현재 실행 화면은 src/main.tsx에서 src/Game.tsx를 불러옵니다.

- src/Game.tsx: 타이틀, 사건 컷신, 현장 조사, 심문 화면, 로컬 엔진, 랭크 엔딩
- src/assets/: 금고 배경과 용의자 초상 이미지
- src/index.css: 반응형 화면과 게임 스타일
- src/App.tsx: 이전 UI 프로토타입
- api/interrogate.ts, src/lib/llm.ts: 현재 게임에서 호출하지 않는 서버 연동 실험 코드

## 🚀 시작하기

**요구 사항**: Node.js 18 이상, npm 9 이상

```bash
# 1. 저장소 클론
git clone https://github.com/blossom0948/code-red-vault.git
cd code-red-vault

# 2. 의존성 설치
npm install

# 3. 개발 서버 실행 (http://localhost:5173)
npm run dev
```

빌드 및 미리보기:

```bash
npm run build      # 타입 체크 + 프로덕션 번들 (dist/)
npm run preview    # 빌드 결과 로컬 미리보기
npm run typecheck  # 타입 체크만
```

빌드 결과물(`dist/`)은 정적 호스팅에 그대로 올릴 수 있습니다 (GitHub Pages, Cloudflare Pages, Vercel 등).

### 정적 배포

npm run build로 생성한 dist/를 GitHub Pages, Cloudflare Pages, Vercel 등 정적 호스팅에 올리면 됩니다. 게임 플레이 중 외부 AI API나 이미지 서버에 요청하지 않습니다.
